# 公开版范围

实验于 2026-11-04（Asia/Shanghai）在真实鲲鹏 TaiShan-v110 服务器执行。公开内容统一放在 `huawei-computing-practice/kunpeng-numa-locality`，与已有鲲鹏、昇腾实验一起维护。

公开材料保留全部 144 条计时记录、16 次全页位置查询、每组原始标准输出和检查日志、编译选项、汇编与实测源文件校验值。数值没有按快慢筛选；原始计时与页面计数不作改写。

环境采集采用字段白名单，不收集连接别名、登录名、主机名、IP、个人目录、凭证、机器专用 Nix store 路径、实时负载或漏洞状态。物理 socket 编号仅映射成相对 `socket_group`，不记录机器身份。原始记录使用 CPU/节点编号与相对时间，不包含内存虚拟地址。

服务器构建二进制、SSH 配置和个人连接信息不在公开目录内。实验只绑定新进程的 CPU 与内存策略，并对自身映射执行全页查询；不修改系统全局策略，不请求迁移其他进程内存。

源码与运行脚本的 SHA-256 在服务端实验完成后记录；另行生成的 `manifest-sha256.txt` 标识公开交付文件。已有其他项目的未提交材料不属于本次发布范围。
