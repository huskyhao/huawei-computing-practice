# 公开版处理说明

本仓库从 2026-11-02 的真实实验交付中单独导出，以新建仓库和全新提交历史发布。

已移除的内容包括：

- SSH 主机别名、登录用户名、远端个人目录、Windows 个人路径。
- 机器专用 Nix store 路径、derivation 路径和部署构建标识。
- 原始环境日志中的运行时长、在线用户计数、负载、实时内存与交换空间使用情况、漏洞状态明细。
- 服务器二进制及其校验清单、压缩包、私人连接配置和原项目历史。

`measurements/environment.txt` 为原始日志的脱敏摘录；`toolchain.txt` 保留版本、目标架构和实际查询到的向量化选项，移除机器专用路径。博客和 README 中的相应描述同步调整。

以下证据保持原实测文件的字节内容：

- `src/` 中四个源文件与 `scripts/run.sh`，由原 `source-sha256.txt` 验证。
- `measurements/raw.csv` 中全部 110 条批次记录。
- 五份汇编、向量化报告、正确性检查日志、编译选项与实验起止时间记录。
- 根据同一批数据生成的 PNG 配图。

`manifest-sha256.txt` 另行记录公开版本的文件校验值。脱敏不改变实验数值或加速比；环境与工具链文本为公开衍生记录，不应称作未处理的原始环境日志。

复现实验生成的新环境日志仅保存在本机，不会被脚本自动上传。公开自己的重跑结果前，应重新检查路径、身份标识和运行状态字段。

## 合集迁移

2026-11-03，本公开项目与原始公开 Git 历史一并迁入 `huawei-computing-practice` 的同名子目录。复现入口和导航已改为合集路径，实验源码、原始数值、汇编与配图保持原内容；公开版本清单随文档变更更新。
