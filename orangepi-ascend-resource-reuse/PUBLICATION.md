# 公开材料范围

本目录包含适合公开分享的博客、两张配图、可复现源代码、固定 Python 依赖和脱敏数值材料，统一维护于 [huawei-computing-practice / orangepi-ascend-resource-reuse](https://github.com/huskyhao/huawei-computing-practice/tree/main/orangepi-ascend-resource-reuse)。

保留全部 24,000 条正式逐请求标量计时，包括较慢记录；另保留十二个独立进程的阶段计时。配置与输出检查计数直接来自实机执行，汇总由复核脚本重算，不改性能数值。

不将连接配置、凭证、个人目录、IP、主机名、进程 ID、完整机器日志或 CANN/模型二进制放入分享版本。通用的 CANN 安装路径、环境变量形式的示例路径与模型文件哈希属于复现所需信息。

完整材料另外保存在本地和开发板：模型、测试张量、参考权重、验证数组、试跑记录及环境和运行日志。公开 metadata 中的输出一致性来自实验执行时的逐请求断言；普通电脑上的统计复核不能代替在开发板重新推理，也不意味着公开了所有原始输出。

环境摘要保留了已有告警和负载均值异常。性能结论仅针对本文软硬件、小模型、静态 batch 与计时范围。
