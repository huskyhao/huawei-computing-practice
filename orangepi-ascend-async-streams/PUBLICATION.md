# 公开版处理说明

本实验于 2026-11-03（Asia/Shanghai）在 Orange Pi AIpro 实机完成，现在作为合集中的独立子目录发布。

公开内容为代码、报告、两张配图和白名单导出的数值记录。以下内容保留在原始本地实验目录，不纳入 Git：

- 原始机器环境与运行时诊断日志、SSH 连接信息、个人目录。
- 探测日志中的 PID、精确错误时间、进程内模型 ID 和完整调用堆栈。
- ONNX/OM 二进制、模型权重与逐样本 NPZ 数组。
- 可能带有本机 CANN 安装路径的完整 pip freeze 记录。

`measurements/formal.json` 保留全部性能、正确性和计时设置，进程内模型 ID 改为实例数量及角色名称。`probe-summary.json` 只保留探测条件、返回码、输出有效性和错误摘要。`local-verification.json` 记录当时对本地完整材料的核对结果，不代表公开目录包含原始数组。

`formal_windows.csv` 保留全部 19,200 行数值记录，未筛除慢样本，浮点数值与原记录一致。Git 可以规范化文本换行，但不会改变 CSV 字段。公开结果可通过 `scripts/verify_public_results.py` 重新计算核对。

原有实验模型作为本次固定负载，新的实验变量是执行策略、等待频率和请求窗口 W。独立准确率测试的样本数为 360；性能循环重复使用既定输入，不将重复调用数当作新的测试集规模。

重跑代码只在当前设备生成材料，不会自动上传任何数据。
